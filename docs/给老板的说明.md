# 关于《Excel 垃圾清理工具》的说明

## 一句话结论

这个工具**只删除已经失效、或没有任何地方引用的"索引条目"（定义名称）和"死链接"（外部链接）**，不会改动任何单元格、公式、图表和格式。以实际文件验证：清理前后 **48 万个单元格逐一比对、强制全量重算后完全一致**。

## 打个比方

Excel 文件里的内容可以分成两层：

- **正文**——单元格数据、公式、图表、格式。**一个字都不动。**
- **索引卡片**（定义名称）和**通讯录**（外部链接）——只抽掉两类：
  - **已作废的卡片**：值本身就是 `#REF!`、`#N/A` 这种错误标记，它指向的位置早已不存在；
  - **从没被人用过的卡片**：整个工作簿的公式、图表、条件格式、数据验证里，没有任何一处引用它。

文件慢的根源正是这些"死卡片"和"死链接"：Excel 打开文件时要一条条去解析它们，其中不少还指向已经失效的网络路径，导致打开时卡顿、反复弹"更新链接"提示。

## 只删什么（以及为什么删了不影响结果）

| 删除对象 | 判断标准 | 为什么不影响任何结果 |
|---|---|---|
| 值已失效的定义名称 | 值本身是 `#REF!` / `#N/A` 等错误标记 | 它指向的位置已不存在，引用它的公式本来就已经是错的 |
| 无人引用的定义名称 | 全工作簿（公式、图表、条件格式、数据验证）里都找不到这个名字 | 没有任何地方用它，删除后计算结果不变 |
| 无人引用的外部链接 | 没有任何公式引用它 | 只是指向外部文件的死链接，还会拖慢打开速度 |

## 绝不碰什么

- 所有单元格内容和公式（逐格比对证明 100% 一致）
- 工作表（数量、名称、顺序不变）
- 图表、图形、图片
- 单元格格式、条件格式、数据验证
- 合并单元格、批注、打印设置、页面布局

## 三道保险

1. **默认只生成新文件**，不覆盖原文件（输出为"`原文件名 - 已清理.xlsx`"）；
2. **写文件前自动校验**输出包结构，任何一条不过就整个丢弃，原文件毫发无损；
3. 确需覆盖原文件时，**自动保留 `.bak` 备份**。

## 独立复核（不依赖工具自证）

`tests\Verify-NoLoss.ps1` 用 **Excel 真实打开**两个文件逐格比对，本次结果 **13/13 全部通过**：

- **480,539 个单元格**：公式逐格一致、计算结果逐格一致；
- **决定性测试**：对清理后的文件**强制全量重算**——如果误删了任何一个仍在使用的名称，用到它的单元格会立刻变成 `#NAME?` 错误，逐格比对必然发现。结果 **0 个差异**；
- **错误值单元格**：清理前 2 个 → 清理后 2 个，**没有新增任何错误**；
- 包内部件层面：只有 3 个元数据文件被改写，被删除的 745 个部件全部属于外部链接。

复核命令（任何人都可以自己跑）：

```powershell
powershell -ExecutionPolicy Bypass -File "D:\DEV\XlsxDoctor\tests\Verify-NoLoss.ps1" `
  -Original "原文件.xlsx" -Cleaned "清理后.xlsx"
```

## 使用建议

1. 用清理后的文件做日常使用（打开快、不再卡死链接）；
2. 原文件保留 1~2 周，确认无任何异常后再自行删除；
3. 若要长期使用，建议把清理步骤加进文件归档流程：先清理、再归档。
